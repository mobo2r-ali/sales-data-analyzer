Sales Data Analyzer

A beginner-friendly Python project for analyzing sales data using Pandas and Matplotlib.

Project Overview

This project analyzes a sample sales dataset to discover useful insights about revenue, products, categories, months, and regions.

Features

- Load and explore sales data using Pandas
- Check for missing values and duplicate records
- Calculate total, average, highest, and lowest revenue
- Analyze revenue by product and category
- Analyze monthly and regional revenue
- Visualize sales data using Matplotlib

Requirements

- Python 3
- Pandas
- Matplotlib
- Jupyter Notebook

Installation

Clone the repository:

git clone https://github.com/mobo2r-ali/sales-data-analyzer.git

Install the required libraries:

python -m pip install -r requirements.txt

Usage

Start Jupyter Notebook:

python -m notebook

Open "notebooks/sales_analysis.ipynb" and run the cells.

Dataset

The project uses a sample sales dataset containing:

- Order ID
- Date
- Product
- Category
- Quantity
- Unit Price
- Region
